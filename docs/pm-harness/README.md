# PM Harness

PM Harness 是一个 AI Product Manager Harness 项目。

它的目标不是直接生成一份看起来完整的 PRD，而是通过阶段化澄清、范围控制、独立评审和决策留痕，把模糊的产品想法转化为可评审、可执行、可交接的产品文档。

## 项目重点

- 不是单一 prompt，而是一套受控 workflow
- 将需求澄清、MVP 收敛、文档生成、独立评审串成闭环
- 通过关键文档展示 AI workflow 的结构化设计能力

## 项目定位

这个项目更偏向 AI workflow / harness 设计，而不是传统应用开发项目。  
重点展示的是：如何围绕 agent 设计阶段、门禁、评审和交接结构。
